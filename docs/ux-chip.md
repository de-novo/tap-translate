# 칩 UX 설계

| 항목 | 내용 |
| --- | --- |
| 대상 | 작성자 1인. 지금 쓰는 사람은 나뿐이다 |
| 기준 | 2.0 칩 (접힘 → 펼침+번역) |
| 상태 | 구현. 접힌 칩이 본체, 트레이는 서랍 |

관련: [기획서](planning.md)

## 지금 무엇이 거슬리는가

접힌 칩의 아이콘을 누르면 **패널이 열리고 번역이 같이 시작**된다.

```
접힘 + 원문     → 탭 → 펼침 + 번역
접힘 + 번역됨   → 탭 → 펼침만
항상 번역       → 로드 → 펼침 + 번역
단축키          → 번역/원문 + 펼침
```

번역은 페이지를 바꾸는 일이다. 패널은 언어·항상 번역·숨기기를 만지는 일이다. 두 일이 한 탭에 묶여 있다.

혼자 쓸 때 실제 손은 이렇게 간다.

1. 영어 페이지를 연다.
2. 칩을 한 번 눌러 글을 바꾼다.
3. 가끔 원문으로 되돌린다.
4. 언어는 거의 안 바꾼다. 패널을 읽을 이유가 거의 없다.

그런데 매번 280px 카드가 본문을 가린다. 닫으려면 X를 한 번 더 눌러야 한다. 항상 번역을 켜 두면 페이지를 열 때마다 카드가 열린다.

## 목표

- **탭 한 번 = 페이지를 바꾸거나 되돌린다.** 패널은 열리지 않는다.
- 패널은 설정이다. 일부러 열 때만 보인다.
- 번역 중·완료·실패는 접힌 칩 위에서 보인다.
- 드래그는 지금처럼 그립(또는 칩 몸통)으로 한다.

## 추천: 접힌 칩이 본체다

패널을 번역 UI의 중심으로 두지 않는다. 작은 칩이 본체이고, 트레이는 서랍이다.

### 접힌 칩

```
[ ⋮⋮ ] [ 文A ] [ ▾ ]
 그립    본탭    서랍
```

| 영역 | 동작 |
| --- | --- |
| 그립 | 드래그. 클릭 없음 |
| 文A | 원문이면 번역. 번역됐으면 원문. 접힌 채 유지 |
| ▾ | 트레이 열기. 번역하지 않음 |

아이콘과 캐럿을 나누는 이유: 롱프레스는 내가 쓰기엔 느리고, 실수와 드래그와 겹친다. 두 칸이면 손이 헷갈리지 않는다.

칩이 너무 넓어지면 캐럿을 빼고, 아이콘 **탭 = 토글**, 아이콘 **오른쪽 얇은 칸**만 서랍으로 둬도 같다.

### 칩이 보여 주는 상태

| 상태 | 칩 | 탭 |
| --- | --- | --- |
| 원문 | 기본 테두리 | 번역 시작 |
| 번역 중 | 아이콘 아래 3px 진행 바. 문A는 그대로 | 무시 (busy) |
| 번역됨 | 테두리/아이콘을 primary로 | 원문 복원 |
| 이미 목표 언어 | 짧은 힌트 후 원문 상태로 | — |
| 실패 | 테두리 destructive. 작은 점 | 트레이를 열어 재시도 / Google 번역 |

실패만 트레이를 연다. 성공 경로에서 패널이 열리면 안 된다.

### 트레이 (지금 카드)

열리는 내용만 남긴다. 번역/원문 큰 버튼 두 개는 뺀다. 그 일은 접힌 칩의 본탭이다.

- 목표 언어
- 다른 언어 항상 번역
- 이 사이트에서 숨기기
- 실패 시에만 상태 문구 + 액션
- 닫기 (X 또는 캐럿 재탭 또는 바깥 클릭)

언어를 바꾸면, **이미 번역된 페이지일 때만** 다시 번역한다. 원문 상태에서 언어만 바꿔 두고 닫으면 다음 본탭에 새 언어가 쓰인다.

## 동작 표

| 입력 | 지금 | 이후 |
| --- | --- | --- |
| 아이콘 탭 (원문) | 펼침 + 번역 | 접힌 채 번역 |
| 아이콘 탭 (번역됨) | 펼침만 | 접힌 채 원문 |
| 캐럿 탭 | 없음 | 트레이만 열림 |
| 항상 번역으로 페이지 진입 | 펼침 + 번역 | 접힌 채 번역. 칩만 완료 상태로 |
| `Alt+Shift+T` | 토글 + 펼침 | 토글. 펼치지 않음 |
| 드래그 | 위치 저장 | 동일 |
| 실패 | 펼친 카드에 문구 | 칩에 점. 탭하면 트레이 |

## 검토했다가 버린 안

**탭하면 펼치기만, 번역은 카드 버튼.**  
패널을 안 열고 번역하고 싶은 나와 반대다. 탭이 한 번 더 는다.

**아이콘 탭 = 번역, 롱프레스 = 패널.**  
드래그와 구분이 나쁘다. 이미 4px 이동으로 드래그를 가르고 있다.

**번역 중에만 카드를 열기.**  
진행을 보려는 마음은 이해한다. 다만 매번 본문을 가린다. 진행 바를 칩에 붙이는 편이 낫다.

## 구현 때 손대는 곳

설계만의 메모. PR 단위는 아직 나누지 않는다.

- `WidgetApp.tsx` — `onFabClick`에서 `setExpanded(true)` 제거. 본탭은 `translator.state`로 번역/원문 토글. 캐럿으로만 `expanded`.
- `translateToTarget` — 성공 경로에서 `setExpanded(true)` 제거. 실패만 연다.
- 항상 번역 effect, 단축키 핸들러 — `setExpanded(true)` 제거.
- 접힌 칩 — 진행 바, 번역됨/실패 시각 상태, 캐럿.
- 트레이 — 원문/번역 그리드 버튼 삭제.

설정 키는 바꾸지 않는다.

## 열린 결정

구현 전에 이것만 정하면 된다. 초안 가정은 괄호 안.

1. 번역된 다음 아이콘을 다시 누르면 **원문으로 토글**한다. (예)
2. 실패가 아니면 트레이를 **자동으로 열지 않는다.** (예)
3. 캐럿을 둘 공간이 아까우면, 그립 반대를 **얇은 서랍 칸**으로 한다. (캐럿 쪽이 더 분명해서 우선)
4. 트레이를 연 채로 본탭(번역)을 할 수 있게 둘지. (아니. 트레이가 열려 있으면 닫기만. 번역은 접힌 뒤에)
